# FAQ Chatbot - Task 2 🤖

## Overview
This is an AI-powered Chatbot designed to answer Frequently Asked Questions (FAQs) using Natural Language Processing (NLP). It uses **Cosine Similarity** to match user queries with pre-defined questions and provides the most relevant answer.

## Project Details
- **Internship:** Artificial Intelligence at CodeAlpha
- **Task Number:** 02
- **Technologies:** Python, Streamlit, Scikit-learn (NLP)

## How it Works
1. The chatbot takes user input via a Streamlit interface.
2. It processes the text and compares it with the FAQ dataset using **TF-IDF Vectorization**.
3. It returns the answer with the highest similarity score.

## How to Run
1. Install requirements: `pip install streamlit scikit-learn`
2. Run command: `streamlit run app.py`
